## 📖 Descripción general

Este repositorio contiene el código fuente de mi **sitio web personal** — un hogar digital para mis proyectos, escritos, lista de lectura, metas de vida y una línea de tiempo de crecimiento.

Diseñado con intención, combina **maestría técnica** con **expresión personal**, reflejando tanto mi rigor en ingeniería como mis valores sobre equilibrio, sostenibilidad y sentido.

### Desarrollado con

- **Astro** — Generación rápida de sitios estáticos centrada en el contenido  
- **Tailwind CSS** — Tema oscuro personalizado basado en zinc  
- **Pestañas y filtros en CSS puro** — Sin JavaScript para la navegación principal  
- **Responsivo y accesible** — Optimizado para móviles y escritorio  
- **Rendimiento primero** — Puntuaciones de Lighthouse consistentemente por encima de 95

## 🎨 Filosofía de diseño

- **Profundidad monocromática**  
  Paleta en escala de grises apilada (zinc-950 → zinc-100) con acentos sutiles

- **Fondos temáticos**  
  Cada página cuenta con un fondo único inspirado en gruvbox o abstracto en SVG/WebP

- **Ritmo tipográfico**  
  - Cuerpo: *Courier New* (raíces de terminal)  
  - Títulos: Serif para contraste y claridad

- **Sin sobrecarga**  
  Cero JavaScript del lado del cliente para pestañas, filtros o navegación

- **Claridad sobre el ruido**  
  Cada píxel sirve a la legibilidad, el enfoque y la calma

---

## 🛠️ Destacados del stack tecnológico

- **Framework:** Astro (SSG)
- **Estilos:** Tailwind CSS con personalizaciones de `@layer`
- **Gestión de estado:** Combinadores de hermanos CSS (`:checked ~`)
- **Gestión de contenido:** Centralizado en `src/pages/data/content.js`
- **Despliegue:** Listo para Vercel, Netlify o GitHub Pages
